# Vibe Coder → Vibe Builder: series assets

Generated educational artwork and editable import packages saved from this chat at the owner's request.

- `original-carousel/`: the original eight exported 1080 × 1350 PNG slides.
- `original-layered/`: the requested original illustrated treatment rebuilt with editable main text and shape layers, eight posts plus a ninth comparison summary. Includes PNGs, SVG backups and a native Figma development plugin (`manifest.json` + `code.js`).
- `editorial-alternative/`: the separate editorial redesign, retained as an alternative rather than replacing the original.
- `original-contact-sheet.png`: the first generated combined preview.
- `post-10-voice-coding.png`: continuation of the series, “Speak the intent. Build the system.” This post is a raster image, not a layered Figma source.

## Edit in Figma

Extract or check out the relevant folder. In Figma desktop, use Plugins → Development → Import plugin from manifest, select `manifest.json`, and run the named plugin. It creates the nine slide frames in the current Design file. No external network access is requested by the plugins.

The original-layered version preserves original illustrations and UI diagrams as separate raster image layers. Small labels and characters inside those illustration crops remain baked in; they are not individually editable vectors. Main headings, prompts, body copy and callout shapes are native editable layers. SVG import may outline text, so use the plugin for live text. The editorial alternative uses editable vector placeholder portraits.

No Figma cloud file was created during this chat; the packages provide local import into a chosen file.
