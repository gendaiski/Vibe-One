ORIGINAL CAROUSEL — 8 POSTS + MATCHING SUMMARY

In Figma desktop: Plugins > Development > Import plugin from manifest. Select manifest.json from this extracted folder, then run Original Vibe Carousel — Layered.

Headlines, prompts, body copy and callouts are native editable text. Accent shapes and prompt panels are editable shapes. Original illustrations and UI diagrams are preserved as separate raster image layers; small labels inside those illustrations remain baked in. Characters remain within those artwork layers. This is not a reconstruction of the illustrations as editable vectors.

SVG backups and PNG exports are included. Importing SVGs may outline text in Figma: use the plugin for live editable text. All slides are 1080 x 1350.
