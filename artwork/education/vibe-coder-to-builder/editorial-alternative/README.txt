9 editable Instagram posts, 1080 x 1350.

Native Figma layers (recommended):
1. Extract this ZIP.
2. In Figma desktop, open a Design file.
3. Plugins > Development > Import plugin from manifest.
4. Select manifest.json and run Vibe Builder — Editable Carousel.

This creates native text, rectangles, ellipses and grouped portraits. All copy remains editable. The plugin uses Manrope when available, then DM Sans, Arial or Inter. No network access.

SVG files are also included as vector backups. Figma may outline SVG text on import; use the plugin for editable typography.

Portraits on slide 1 are deliberately simple editable placeholders grouped as Characters / replace these. The other slides use diagrams instead of character artwork.
